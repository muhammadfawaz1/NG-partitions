# N&G Partitions Website

Premium portfolio website for N&G Partitions LTD, built with Next.js, TypeScript,
Tailwind CSS and Framer Motion.

## Run Locally

```bash
npm install
npm run dev
```

Production preview:

```bash
npm run build
npm run start
```

## Project Structure

- `src/app` - App Router pages, dynamic service routes and project case studies.
- `src/components` - Reusable layout, section, card, media and UI components.
- `src/data` - Static service, project and site content.
- `public/assets` - Organized video and image assets.

## Checks

```bash
npm run lint

```
